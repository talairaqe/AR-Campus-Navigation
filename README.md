# CSEway — Indoor Navigation MVP

CSEway is a minimum viable product for indoor navigation inside the Engineering building on campus. Since GPS is unreliable indoors, the project focuses on image-based location recognition: the user captures (or uploads) a photo of a sign (room label or cafeteria sign), and the system uses OCR to identify where the user is currently located. After the location is detected, the user enters a destination, and the app provides a simple navigation instruction for the current milestone. Finally, the user captures (or uploads) an arrival photo to verify that the destination was reached, and the app marks the destination text with a clear arrow on the image.

For this milestone, the intended demo flow is as follows: the user opens the app and provides a start image from the camera or gallery. The app runs OCR and displays a message indicating the detected location (“You are at: …”). If a location is detected successfully, the user can type a destination. The app then shows a basic navigation instruction (currently modeled as walking straight 44 meters). The user then provides a second image (arrival image). If the destination is detected in the arrival image, the app returns the same image annotated with a red arrow pointing to the destination label; otherwise, an error message is displayed.

The current MVP supports a limited set of known places for demonstration purposes, including room codes such as C320 and cafeteria names such as FABiOLA and BITES&BEATS. The matching logic is robust to small OCR errors by using normalization (e.g., handling common confusions like “O” vs “0”), simple substring checks, and fuzzy similarity scoring to select the best candidate among the detected text results. The set of supported rooms and aliases can be extended easily by adding more entries to the known places list.

The repository includes two implementations that serve different purposes. The Python version is used as a fast prototype for OCR-based detection and for generating annotated images with arrows, which helps validate the recognition and matching logic. The iOS version is an on-device SwiftUI application that performs OCR using Apple’s Vision framework and provides a simple user interface for capturing or selecting images, detecting the current location, entering a destination, and verifying arrival with an annotated output image.

This project is an MVP designed for a short demo and can be expanded in future iterations. Possible next steps include real-time camera processing, AR overlay guidance inside the building, multi-step routing based on an indoor map graph, and a larger database of rooms and landmarks.
